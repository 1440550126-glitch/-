## 第 1 讲　电路是一个圈：四样东西缺一不可

电和水很像。水要流动得有水泵、水管、水龙头、花洒；电要流动，也得凑齐四样东西，而且必须连成一个**闭合的圈**——断开任何一处，电就不走了。

```
        电源＋            开关                       电流方向
          │        ┌──────/  ──────┐        →  从＋极出发
     ┌────┴───┐    │               │           经开关
     │  ══════│────┘               │           流过灯泡
     │  ────  │                   ─┴─          回到−极
     └────┬───┘                  ( ╳ )  灯泡（用电器）
        电源−                     ─┬─
          │                        │
          └────────────────────────┘
                    导线
```

| 部件 | 干什么的 |
|---|---|
| **电源** | 提供电压（推力）。电池、插座来的电 |
| **开关** | 控制通断。断开＝停电 |
| **用电器（负载）** | 把电变成光、热、转动。灯、电机、电器 |
| **导线** | 电流走的路，本身不干活 |

### 图上的线交叉了，到底连不连？

规矩只有一条：**有实心黑点 ＝ 连在一起；没有点 ＝ 只是画面上交叉而过**（现实中两根线一上一下跨过去，互不相干）。

```
     │                  │
  ───●───   接通      ──┼──   不接（画成断开的竖线表示只是跨过）
     │                  │
```

看漏一个小黑点，整张图就读反了。养成习惯：先找黑点。

## 第 2 讲　常用符号速查

电路图不画实物，画的是**符号**——全世界统一，认得它就等于识字。字母是**文字符号**（器件代号），图纸上用它点名。

| 符号画法 | 名称 | 代号 | 白话解释 |
|---|---|---|---|
| `──┤├──`（长线＋短线） | 直流电源 / 电池 | `GB` | 长线是正极＋，短线是负极− |
| `──(∼)──` | 交流电源 | `AC` | 圆圈里一条波浪线。家里 220V 就是交流 |
| `──•/ •──` | 开关 | `SA / S` | 一条抬起来的"闸刀"。抬起＝断开 |
| `──•/ •──` 上带推杆 | 按钮（常开） | `SB` | 按住才通，手一松就弹开 |
| `──(╳)──` | 照明灯 | `EL` | 圆圈里打个叉 |
| `──[ ]──` | 电阻 | `R` | 小方块，"卡住"电流顺便发热 |
| `──[═]──` | 熔断器 / 保险丝 | `FU` | 电流太大它先烧断，替电器挡灾 |
| `──•/✕•──` | 断路器（空开） | `QF` | 开关头上加个"✕"，会自己跳闸 |
| `──┴ ≡` | 保护接地 | `PE` | 三条越来越短的横线，漏电时把电引进大地 |
| `──(M)` | 电动机 | `M` | 圆圈里写 M |
| `──[KM]──` | 接触器线圈 | `KM` | 通电变电磁铁，小电流指挥大电流 |
| `──•/ •──` / `──•─•──` 带斜杠 | 常开 / 常闭触点 | `KM`、`FR` | 常开＝平时断着；常闭＝平时通着 |

## 第 3 讲　串联和并联：家里为什么全是并联

```
串联 · 一条路走到底                   并联 · 各走各的路

   ┌───(╳)────────┐                 ┌────────┬────────┐
   │              │                 │        │        │
  ═╪═            (╳)               ═╪═      (╳)      (╳)
   │              │                 │        │        │
   └──────────────┘                 └────────┴────────┘

 拆掉一盏 → 另一盏也灭              拆掉一盏 → 另一盏照常亮
 电压被两盏分掉，都偏暗              每盏都吃满 220V，一样亮
```

**结论：家里的灯、插座、电器全部是并联**——所以每个都能拿到完整的 220V，坏一个不影响别人。

**顺带记三个名词**：电压（V，伏）＝推力；电流（A，安）＝流量；功率（W，瓦）＝干活速度。
家用记一个换算就够：`功率 ÷ 220 ≈ 电流`。2200W 的浴霸约 10A，那一路空开至少 16A。

## 第 4 讲　一个开关控制一盏灯（单控）

```
 ┌────────┐   火线 L（红/棕）      开关（必须装在火线上）
 │        ├──────────────────•/  •──────────────┐
 │ 配电箱 │                                     │
 │空开/漏保│   零线 N（蓝）                     ┌─┴─┐
 │        ├────────────────────────────────────( ╳ )  灯
 │        │                                    └─┬─┘
 │        │   地线 PE（黄绿）                    ┆ 接灯具金属外壳
 └────────┴──────────────────────────────────────┘
```

**为什么开关一定要切火线？**
开关断开后，灯头那一段就彻底没电了——你站在凳子上换灯泡才是安全的。
要是接反了（开关切零线），关了灯，灯头照样带 220V 火线电，手一碰就触电。**这是最容易出人命的接反。**

## 第 5 讲　楼梯灯：两个地方管一盏灯（双控）

用两个**单刀双掷开关**，中间两根"跨接线"连起来。

```
 ┌────────┐  火线 L        L1
 │        ├────────•        ┌──────────•
 │ 配电箱 │         \       │           \        ┌─┐
 │        │          •──────┘            •──────( ╳ ) 灯
 │        │         开关A       L2      开关B    └┬┘
 │        │        （楼下）  ┌──────────•         │
 │        │                  •                    │
 │        │  零线 N                               │
 └────────┴───────────────────────────────────────┘
```

**图上这个状态**：两个开关都搭在 L1 上 → 路通了 → **灯亮**。
随便拨动其中一个开关，它换到 L2，两头对不上 → 路断了 → **灯灭**。
所以任何一个开关都能单独控制这盏灯。

## 第 6 讲　家里的配电箱：电是怎么分出去的

```
                                              ┌──────────────┐
                                         ┌───▶│ 照明 1P 10A  │→ 客厅/卧室灯
 ┌──────────┐   ┌──────────┐   ┌───────┐ │    └──────────────┘
 │ 电表进线 │──▶│  总开关  │──▶│漏电保护│─┤    ┌──────────────┐
 │   L / N  │   │QF0 2P 40A│   │RCD 30mA│ ├───▶│ 插座 2P 16A  │→ 各房间插座
 └────┬─────┘   └──────────┘   └───────┘ │    └──────────────┘
      │                            汇流排 │    ┌──────────────┐
      │ 地线 PE                          └───▶│ 空调 2P 20A  │→ 空调专线
      ▼                                       └──────────────┘
     ─┴─  接地排 → 每个插座的地脚 / 所有金属外壳
      ≡
```

**三道防线，各管各的：**

| 器件 | 管什么 | 说明 |
|---|---|---|
| 总开关 QF0 | 管"全家断电检修" | 拉下它，全屋断电 |
| **漏电保护器 RCD** | **管人** | 发现电从你身上漏走了，30ms 内跳闸 |
| 各路空开 QF1/2/3 | 管线 | 某一路电流超了只跳它自己，不牵连别人 |

> **漏保和空开不是一回事，缺一不可。**

**跳闸了怎么查？**
跳的是某一路空开 → 那一路超载或短路，拔掉那路的大功率电器再合闸。
跳的是**漏保** → 说明有漏电（潮湿、电器坏了、或者有人触电），**别硬合闸**，逐路排查，查不出就叫持证电工。

## 第 7 讲　三孔插座与线色

面对插座正面，三个孔的位置是**国标固定死**的：

```
        ┌───────────────┐
        │     ▭  地 PE  │      口诀：左零 · 右火 · 上接地
        │               │
        │   ▯       ▯   │
        │  零N      火L │
        └───────────────┘
          （从正面看）
```

| 线 | 颜色 | 说明 |
|---|---|---|
| 火线 **L** | 红色 或 棕色 | 带电的那根 |
| 零线 **N** | 蓝色 | 电流的回路 |
| 地线 **PE** | **黄绿双色** | 只能当地线用，永不挪作他用 |

**怎么分辨哪根是火线？** 用**验电笔**（试电笔）：笔尖碰线芯、手指按住笔尾金属，**氖管发亮的就是火线**；零线和地线都不亮。这是电工每天都在用的第一件工具，几块钱一支，必须常备。

## 第 8 讲　电机启停自锁（考证必考）

要求：**按一下启动按钮，电机一直转；按一下停止按钮，电机停。**
难点：按钮一松手就弹开了，靠什么让电机继续转？答案是**自锁**。

这类图永远分左右两半：**主电路**（粗线，大电流，真正驱动电机）和**控制电路**（细线，小电流，负责发号施令）。

```
  主电路 · 大电流干活              控制电路 · 小电流指挥

  L1  L2  L3  三相电源             L                              N
   │   │   │                       │  FR常闭  SB1停止  SB2启动    │
 ┌─┴───┴───┴─┐                     ├───•─/─•──•─/─•──┬─•  /•─┬─[KM]┤
 │ QF 断路器 │                     │                 │        │  线圈
 └─┬───┬───┬─┘                     │                 │        │
 ┌─┴───┴───┴─┐                     │                 └──•  /•─┘
 │ KM 主触点 │                     │                  KM 自锁触点（常开）
 └─┬───┬───┬─┘
 ┌─┴───┴───┴─┐
 │FR 热继电器│
 └─┬───┬───┬─┘
   └───┼───┘
      (M)  三相电动机
       3∼
```

**动作顺序：**

1. 按下 `SB2` → 回路接通 → `KM` 线圈得电
2. `KM` 主触点闭合 → **电机转**；自锁触点同时闭合
3. 松开 `SB2` → 电流改走自锁触点 → **电机继续转**
4. 按下 `SB1` 停止 → 整条回路断 → 全部释放，**电机停**

**自锁的精髓**：KM 线圈通电后，用它自己的一个常开触点把启动按钮"短接"住——相当于自己按住了自己。

这也是**失压保护**：一旦停电，线圈释放、自锁断开，来电后电机**不会自己突然启动**，避免伤人。
**FR 热继电器**则在电机长时间过载发烫时，用它的常闭触点切断控制回路。

## 第 9 讲　安全铁律（比前面八节都重要）

> ### ⚠ 动手之前，这五条一条都不能省
>
> 1. **先断电，再验电。** 拉下空开只是第一步，必须用验电笔**实测确认不带电**才能动手。空开可能是坏的，也可能你拉错了那一路。
> 2. **挂牌上锁。** 在配电箱上贴张纸："有人作业，禁止合闸"。别人顺手一推闸，你就在里面。
> 3. **单手操作，站在干燥处。** 双手作业时电流可能穿过心脏。不要站在水里、湿手作业。
> 4. **金属外壳必须接地。** 地线不是可有可无的第三根线，它是漏电时唯一替你挡枪的东西。
> 5. **36V 以下才算安全电压，220V 完全足以致命。** 只要 30mA 电流通过人体就可能引起心室颤动——这也是漏保定 30mA 的原因。
>
> **入户线、配电箱改造、任何需要动电表和总闸的活，请交给持证电工。**
> 这份讲义帮你看懂图纸和原理，不等于授权你带电作业。

### 常用文字符号总表

| 代号 | 中文 | 干什么的 |
|---|---|---|
| `L / N / PE` | 火线 / 零线 / 地线 | 红棕 / 蓝 / 黄绿 |

### 接下来练什么

1. 拿一个电池、一个小灯泡、一个开关，把**第 1 讲**的圈亲手接一遍，再试着接成串联和并联。
2. 买一支验电笔，在自家插座上找出哪个孔是火线，验证"左零右火"。
3. 打开自家配电箱盖（**只看不动手**），对照第 6 讲认一遍：哪个是总闸、哪个是漏保、每一路管什么。
4. 再回头看第 8 讲的自锁图，用手指顺着线走一遍电流，走通了就说明你真看懂了。
