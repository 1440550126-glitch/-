PLC 梯形图入门
点一下就能看懂

PLC 说白了就是一柜子能改程序的继电器。这一篇把接触器电路搬进 PLC 里，三个梯形图都能真的按按钮跑起来——绿线就是电流，你按哪它走哪。

第 1 讲

PLC 是什么：一柜子能改程序的继电器

回想一下电机启停自锁那张图：一个接触器、两个按钮、一个热继电器，还有一堆按固定方式接死的线。现在要加一个功能——"按下启动，延时 3 秒再转"。

  • 用继电器：买个时间继电器，断电，拆线，重新接，再调试。改一次要半天。
  • 用 PLC：在电脑上把梯形图改两笔，下载进去。五分钟，一根线都不用动。

这就是 PLC 唯一的、也是全部的优势：把"接线的逻辑"变成了"可以改的软件"。至于电从哪来、到哪去、怎么保护，跟你在前面几讲学的一模一样，一点没变。

对比继电器接触器控制PLC 控制
逻辑装在哪装在线里——线怎么接，逻辑就怎么走装在程序里——线只管进出
改功能断电拆线重接改梯形图，下载
做定时/计数要另配时间继电器、计数器软件自带，写一行就有
故障排查万用表一根根量屏幕上直接看哪个触点通了
谁在真正带动电机都是接触器 KM。PLC 自己带不动电机。
第 2 讲

三大件：输入 → CPU → 输出

PLC 只有三部分，认准它的端子就不会接错：左边是输入端子（接按钮、开关、传感器），右边是输出端子（接接触器线圈、指示灯），中间是 CPU 在跑你写的程序。

第 3 讲

梯形图怎么读：像看电路图一样看它

梯形图（Ladder）长得像一架梯子：左边一根竖线是"左母线"，永远带电；每一横档叫一个"梯级"，从左往右走，走得通，右边的线圈就得电。

它其实就是把第 8 讲的控制电路竖着画改成横着画，符号也几乎照搬：

梯形图符号叫什么什么时候能通过对应实物
─┤ ├─常开触点对应的位为 1（ON）时接通启动按钮、接触器常开辅助触点
─┤/├─常闭触点对应的位为 0（OFF）时接通停止按钮、热继电器常闭触点
─( )─输出线圈左边走通就得电，驱动 Y 端子接触器 KM 线圈
X0 X1…输入继电器外面接进来的按钮、开关的状态（只能读）
Y0 Y1…输出继电器输出端子，也可以当触点在程序里反复用
M0 M1…辅助继电器程序内部的"草稿纸"，不接到外面
新手最容易栽的一个坑

程序里画常闭触点 ─┤/├─，不等于外面那个按钮是常闭的。符号说的是"这一位是 0 的时候通"，跟外面接的是什么按钮是两码事。
下面的仿真里，停止按钮 X0 在程序里画成常闭：没按 X0 时 X0＝0 → 常闭触点接通 → 电流能过去；一按 X0 变 1 → 常闭断开 → 整条路断掉。

仿真 1

启保停：PLC 版的自锁

这就是第 8 讲那个自锁电路，一行梯形图搞定。按住下面的按钮试试——按钮是点动的，松手就弹起来，正好看清自锁到底锁住了什么。

绿色 ＝ 有电流从这里流过去了；灰色 ＝ 要么这个触点断着，要么它前面根本没电。

启保停电路

Y0 = （X1 启动 或 Y0 自锁）且 没按 X0 停止

你应该看到的三件事

  1. 按住启动：上面那条支路变绿 → 线圈 Y0 得电 → 输出灯亮。
  2. 松开启动：上面那条灰回去了，但下面 Y0 那条支路接了上来——电流改走自锁路，输出保持。这就是"自锁 / 自保持"。
  3. 按一下停止：X0 常闭断开，整条路断掉，Y0 立刻失电；松开停止后也不会自己恢复，因为自锁那条早断了。
和继电器电路一模一样的对应关系

X0 ↔ 停止按钮 SB1　|　X1 ↔ 启动按钮 SB2　|　Y0 ↔ 接触器 KM 线圈
梯形图里那个 Y0 常开触点，就是实物图里 KM 的自锁辅助触点——只不过在 PLC 里它是"软"的，想用多少个就用多少个，不用花钱买。

仿真 2

正反转互锁：不许两个同时来

电机要能正转也能反转。但正反转接触器绝对不能同时吸合——那等于把两根相线直接短路，"砰"一声，主电路炸给你看。

办法叫互锁：在正转那一档串一个反转的常闭触点，反转那一档串一个正转的常闭触点。谁先动谁把对方锁死。

正反转互锁

正转 Y0 要求「没在反转」；反转 Y1 要求「没在正转」

亲手验证一下

  1. 按一下正转 → Y0 亮，电机正转。
  2. 这时候按反转 → 没反应。因为反转那一档里的 Y0 常闭已经被顶开了。
  3. 先按停止，再按反转 → Y1 亮。必须先停，这就是互锁的意义。

⚠ 只在程序里互锁是不够的

实际工程里必须做双重互锁：程序里互锁一次，接触器的机械/电气常闭触点再硬互锁一次。因为接触器可能触点粘连、PLC 也可能死机——软件锁不住的时候，硬件是最后一道保险。这是行业铁律，不是可选项。

仿真 3

定时器：PLC 真正省事的地方

需求变了：按下启动，等 3 秒再让电机转（比如先让润滑泵打上油）。用继电器要买时间继电器重新接线；用 PLC 就是加两行。

T0 K30 的意思是：定时器 T0，设定值 30 × 100ms ＝ 3.0 秒。只要它前面一直通着就开始数，数满了 T0 这个触点才闭合。中途断一下就清零重来。

延时启动

启动 → M0 自保持 → T0 数够 3 秒 → Y0 输出

试试数到一半按停止——进度条立刻清零。再启动，从头数。这就是"通电延时型"定时器的脾气。

第 7 讲

不同牌子，地址不一样

梯形图的画法全世界通用，但元件地址各家各叫各的。国内新手最常上手的是三菱 FX 系列和西门子 S7-200 SMART。

作用三菱 FX西门子 S7欧姆龙 CP
输入（按钮进来）X0 X1 X2…I0.0 I0.1…0.00 0.01…
输出（去接触器）Y0 Y1 Y2…Q0.0 Q0.1…100.00…
内部辅助（草稿纸）M0 M1…M0.0 M0.1…W0.00…
定时器T0 K30T37 (S5T#3s)TIM 000
计数器C0 K10C0CNT 000
注意三菱的编号是八进制

三菱 FX 的 X、Y 地址没有 X8 和 X9——数到 X7 直接跳 X10。第一次接线的人几乎都在这里数错过端子。

接下来怎么练

  1. 把上面三个仿真每个都按到能预测结果：按之前先说出"哪条会绿、输出会不会亮"，再按下去验证。
  2. 装一个免费的编程软件（三菱 GX Works2、西门子 STEP 7 MicroWIN SMART 都有仿真器），不用买 PLC 也能跑。
  3. 把这三个梯形图照着敲一遍，用软件自带的仿真运行。
  4. 再练三个经典：两地启停（多个按钮并联）、顺序启动（A 转了 B 才能转）、闪烁（两个定时器互相触发）。

⚠ 接实物 PLC 之前

  • 先在仿真器里跑通，再下载到实物。程序错了，电机是真的会动的。
  • 接线时 PLC 必须断电，输入 COM 和输出 COM 分清楚，别把 220V 接进输入端子——那是 24V 的地盘，接错直接烧板子。
  • 输出端子接的是接触器线圈，不是电机。主电路的断路器、热继电器一个都不能省。
  • 急停按钮必须硬接线，直接切断控制回路电源，不能只靠 PLC 程序判断。PLC 死机时，急停仍然必须有效。
